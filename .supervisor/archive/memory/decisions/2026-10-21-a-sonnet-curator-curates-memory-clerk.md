D4. A new agent, `curator`, on Sonnet, distills, supersedes, re-verifies and archives; the `clerk`
records; `scout` (for the supervisor) and the leads (at contract time) retrieve. The curator does no
retrieval for other agents. Why: separating writing from retrieval keeps each agent's context and
tool set small, and Context Preservation forbids the supervisor grepping memory itself.
